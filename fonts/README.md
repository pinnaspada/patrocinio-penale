# Font locali

I file WOFF2 di questa cartella sostituiscono i caricamenti remoti da Google Fonts.
Sono incluse soltanto le varianti `latin` e `latin-ext` effettivamente usate dal portale e dalle applicazioni HTML autonome.

Famiglie: Cinzel, Cormorant Garamond, EB Garamond, IBM Plex Mono, IBM Plex Sans, Inter, JetBrains Mono, Playfair Display, Source Sans 3, Source Serif 4 e Spectral.

Origine: [Google Fonts](https://fonts.google.com/). Le famiglie sono distribuite con le licenze libere indicate nelle rispettive schede Google Fonts, prevalentemente SIL Open Font License; IBM Plex è distribuito secondo SIL Open Font License. I file non devono essere estratti da questa cartella o redistribuiti separatamente senza mantenere i relativi avvisi di licenza.
